# WORKOUT

점진적 과부하 운동 기록 앱이에요. 서버 없이 폰에 설치해서 쓰는 웹앱(PWA)이고, 한 번 열어 두면 인터넷이 없어도 돼요.

- **운동**: 루틴을 만들고 세트마다 무게·횟수를 기록해요. 지난 기록을 보고 다음 목표(+1회, 증량, 디로드)를 자동으로 채워 줘요. 오늘 할 루틴은 루틴 이름만 보이고, ▾를 누르면 운동 목록이, 운동 옆 ▾를 누르면 다음 목표와 세트·횟수·휴식이 펼쳐져요.
- **루틴 편집**: 운동 블록을 꾹 눌러 끌면 순서가 바뀌어요. 한 번 넣은 운동은 루틴 관리의 **내 운동**에 근육별로 모이고, 루틴을 만들 때 **내 운동에서 고르기**로 여러 개를 한 번에 넣어요.
- **단백질**: 몸무게로 하루 목표를 계산하고, 한식·중식·일식·양식·분식 메뉴 156종과 식재료·단백질 음료·파우더 72종을 골라 넣으면 자동으로 합산해요.
- **기록**: 캘린더에서 날짜를 누르면 그날 한 운동을 자세히 볼 수 있어요.
- **성장**: 가슴·등·어깨·팔·하체·코어·유산소 부위별로 운동마다 첫 기록 대비 증가량을 한눈에 보고, 운동을 누르면 추정 1RM·횟수 그래프가 나와요. 체성분 변화도 함께 봐요.
- **코치**: 내 루틴으로 이번 주 근육별 세트를 보여 주고, 일주일마다 정체된 운동을 찾아 조정을 제안해요.

## 폰에 설치하기

- **아이폰**: Safari로 앱 주소를 열고 → 공유 버튼 → **홈 화면에 추가**
- **안드로이드**: Chrome으로 앱 주소를 열고 → 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**

## 데이터

- 기록은 폰 안에만 저장돼요. 서버로 보내지 않아요.
- 폰을 바꾸거나 앱을 지우면 기록이 사라지니, 가끔 **설정 → JSON 내보내기**로 백업해 두세요.
- 백업 파일은 **설정 → JSON 가져오기**로 되돌릴 수 있어요. Claude에서 쓰던 기록도 같은 방법으로 옮겨요.

## 보안 (코드를 고칠 때 지킬 것)

이 앱은 **콘텐츠 보안 정책(CSP)**으로 이 사이트의 파일만 실행·로드해요. 혹시 화면에 끼워넣은 HTML이 생겨도 스크립트가 실행되지 않고, 외부 서버(폰트 포함)에는 접속하지 않아요.

- 자바스크립트는 **`app.js`에만** 쓰기. `index.html`에 `<script>…</script>`를 직접 넣거나 `onclick="…"` 같은 속성을 쓰면 CSP 때문에 실행되지 않아요.
- 외부 스크립트·CDN·폰트를 추가하지 않기. 필요하면 파일을 저장소에 넣고 `index.html`의 CSP 줄과 함께 고치기.
- 사용자가 입력하거나 파일에서 읽은 글자는 화면에 넣을 때 `esc()`로 감싸기.
- 글꼴은 `fonts/` (Fontsource 5.3.0, SIL Open Font License)에 들어 있어요.
- `app.js`나 `sw.js`를 바꾸면 `index.html`의 `app.js?v=…`, `app.js` 안의 `sw.js?v=…`, `sw.js`의 버전 번호를 같은 새 값으로 올려야 폰에 새 버전이 확실히 깔려요.
- Claude 아티팩트로 올릴 때는 아티팩트 환경이 스크립트를 따로 넣을 수 있어서, CSP 줄(`Content-Security-Policy`)이 클라우드 저장 기능을 막을 수 있어요. 그때는 CSP 줄을 빼고 올리세요.
